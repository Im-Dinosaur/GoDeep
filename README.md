현재는 M1의 로컬 조작 시제품이다. `Assets/1. Scenes/Home.unity`를 열고 Play를 누른 뒤 **PREPARE TO DIVE → START LOCAL PRACTICE → DIVE / RESUME**로 실행한다. Fusion·Voice SDK는 설치됐으며 실제 온라인 플레이와 음성 송수신은 후속 단계에서 연결한다.
